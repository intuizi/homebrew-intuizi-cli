# Intuizi Homebrew tap

Homebrew formulas for the [Intuizi CLI](https://github.com/intuizi/intuizi-cli).

```bash
brew install intuizi/intuizi-cli/intuizi
```

Or in two steps:

```bash
brew tap intuizi/intuizi-cli
brew install intuizi
```

The formula in `Formula/` is generated and committed by the intuizi-cli
release workflow (goreleaser) on every `v*` tag. Do not edit it by hand: the
next release overwrites it.
